## Instructor's release policy
Only Week 10 student-facing case materials are posted. Do not publish instructor solutions, unreleased complication notes, or future datasets in this public repository. The cases use real organization backgrounds but fictional local operations, people and data, for classroom education; no association or endorsement is implied.

Each site's HTML is self-contained. Later case updates can be made by editing the appropriate directory's index.html.
